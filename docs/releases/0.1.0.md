# 1git 0.1.0

Lower memory use, clearer reviews, and more control.

## Download

[1git for macOS — Apple Silicon](https://git.1bye.dev/1git-0.1.0-macos-arm64.zip)

Requires macOS 13 or later and Git. Extract the ZIP and move 1git.app to Applications.
This beta is Developer ID signed and notarized by Apple, with a stapled ticket.
Existing users can update through **1git → Check for Updates…** after publication.

When upgrading from an older ad-hoc build such as 0.0.25, macOS may request
one-time Keychain access approval. Choose **Always Allow** for 1git, or explicitly
disconnect and reconnect the affected account in Settings. The new signing
identity cannot silently inherit the old build's credential permissions.

## Highlights

- **Much lower memory use.** The window grain keeps its appearance with smaller shared textures. In matched eight-tab native preview tests, median settled RAM fell from **368 to 140 MiB**, and peak RAM from **607 to 151 MiB**. Actual usage depends on the repositories and views you open.
- **Redesigned Settings.** Grouped pages, side-panel editors, and faithful live previews make customization easier. Adjust repository colors and patterns while seeing the result, and recognize external editors by their macOS icons.
- **List and Tree file navigation.** Switch layouts across Changes, History, Stashes, Graph, and comparisons. Include entire folders, keep your preferred layout, and reveal truncated names on hover or keyboard focus.
- **More AI providers.** Connect Claude Code and Codex CLI accounts, choose provider-specific models and effort levels, and configure OpenAI- or Claude-compatible APIs with private authentication headers.
- **Customizable keyboard shortcuts.** Search commands, change shortcuts, detect conflicts, restore defaults, and move between Spaces.
- **Better sync and conflict review.** Review diverged branches before integration. Compare either conflict source with the working result in an aligned split diff, with highlighted hunks and expandable context. Push remains a separate action.

## More control

- Optionally **automatically include changed files** in commits. This setting defaults off and preserves manual selections.
- Turn **Grain texture** on or off in Appearance settings; your choice is remembered.
- Delete custom Spaces with confirmation. Their repositories, tabs, and drafts move safely to Default.

## Fixes and polish

- Fix Git pushes failing when pre-push hooks run Oxlint or other native Node.js tools.
- Make commit errors and hook output selectable and copyable, including output outside the visible log.
- Show Settings scrollbars when Pane scrollbars is enabled, while keeping headers and actions fixed.
- Prevent repository-search flickering and return filtered results to the top.
- Handle missing editor applications gracefully; removed saved editors remain marked unavailable.
- Prevent cancellation errors when switching AI providers.
- Improve branch-publishing remote selection, automatically choosing the destination when only one remote exists.
- Keep blocked-close notices compact.
- Reject conflict resolutions based on an indexed version that changed after review.
- Preserve History and Stashes file-list scroll positions when switching tabs, and keep file-name hover animations responsive while scrolling.

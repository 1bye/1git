# 1git 0.1.1

Faster repository browsing and more ways to get around.

## Download

[1git for macOS — Apple Silicon](https://git.1bye.dev/1git-0.1.1-macos-arm64.zip)

Requires macOS 13 or later and Git. Extract the ZIP and move 1git.app to Applications.
Developer ID signed and notarized by Apple, with a stapled ticket.
Existing users can update through **1git → Check for Updates…**.

## New

- **Command palette.** Find repositories and actions with **⌘P**, with compact rows, matching icons, and Settings commands ordered for the active tab. Type **>** to search only commands.
- **Welcome and Settings tabs.** Keep Settings open alongside repositories, preserve unfinished edits when switching tabs or spaces, and start new tabs from Welcome.
- **Terminal launcher.** Open the app with `1git`, or a repository with `1git .` or `1git /path/to/repo`. Enable it in **Settings → Application → Install**; choose **Only me** for installation without administrator access.
- **Fetch with ⌘R.** Refresh now fetches remote updates before rereading the active repository. Fetch updates remote branches and ahead/behind counts without pulling or merging.
- **Larger AI selections.** CLI AI agents can generate commit messages for selections beyond the previous 64 KiB limit.

## Fixes and polish

- Keep clone lists responsive with thousands of repositories, with a scrollbar for the full list.
- Keep keyboard-selected commands visible and support navigation across every result.
- Preserve Settings drafts and pending saves when changing tabs or spaces.
- Keep failed terminal-launch requests from opening a tab in a different space after navigation.
- Fix Settings and Welcome scan icons, and simplify the command palette by removing its shortcut footer.

Periodic background fetch is on the roadmap; this release fetches when requested.
